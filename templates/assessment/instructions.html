Test Rules & Evaluation Instructions

  1. The timer starts immediately once you click Begin Assessment.
  2. Your answers are automatically saved to your account in real time.
  3. For coding challenges, you can run and test your solution against sample test cases using the Run Sample Test button before final submission.
  4. Multiple-choice questions award 1 mark for each correct answer; coding challenges award up to 10 marks with partial credit based on passed test cases.
  5. There is no negative marking. Attempt all questions.
  6. Once submitted, you will receive an in-depth score analysis, career readiness level, identified skill gaps, and a full Review Answers walkthrough.
